## Root cause and fixes
1. Android app bundle initially omitted `agent/`, so `server.js` imports would fail at runtime: Android asset Sync now includes it.
2. The old emulator ran without KVM permission and suffered substantial performance issues. CI now explicitly enables and checks `/dev/kvm`.
3. Run 37877402327 proved Alpine extraction's `/bin/sh` **does exist** as a symbolic link to `/bin/busybox`, but Android host `File.exists()/isFile` incorrectly rejected it. `RootfsShellValidator` checks the guest link without host resolution, shared by Alpine and PRoot checks.
