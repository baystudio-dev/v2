## Issues resolved
- Earlier Bash exit 23 resulted from Android routing an immediate `am start` intent to a stale top Activity after force-stop rather than starting a replacement process.
- `--activity-new-task` was not accepted by Android 36, causing a later script exit 26; fixed using `-S -f 0x10008000` (NEW_TASK/CLEAR_TASK).
- Intermittent GitHub hosted-runner KVM permissions prevented emulator startup; workflow now uses a runner-local fallback and bounded readability/writability gate.

## Scope and remaining gates
- This validates **basic Android app restart, embedded Node backend health, and team metadata** on the x86_64 API 36 emulator.
- It does **not** establish full chat/agent execution, terminal/PRoot interactive behavior, private ACL integration, extended lifecycle endurance, native ELF full 16 KiB segment proof, or physical ARM64 app operation.
- Physical ARM64 test **NOT TESTED**. Main remains unchanged; PR #1 stays draft.
